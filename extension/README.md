# Eternity for Chrome

A side panel where your head teammate reads along with you.

- **Ask about any page**: summarize, explain, "what do I actually need to do?"
- **Due dates**: spots due dates on the page and gives you a calendar file for each
- **The Guard**: strips hidden instructions from pages before anything is sent
- Signs in with your Eternity account. Tokens live only in this browser session.

## Try it
1. Open `chrome://extensions`, turn on **Developer mode**.
2. **Load unpacked** and pick this `extension` folder.
3. Pin Eternity and click it to open the side panel. Sign in with the same email and password you use in the app.

It calls the same `callFamily` Cloud Function as the app, so it shares your plan's daily limit.
